# Quiz Teórico Automática — UPM/ETSIDI

App estática offline para estudiar preguntas tipo test de Automática.

## Uso
Abre la URL desplegada desde el móvil. En iPhone puedes usar **Compartir → Añadir a pantalla de inicio**.

## Archivos
- `index.html`: app completa.
- `manifest.webmanifest`: configuración PWA.
- `sw.js`: caché offline.
- `icon.svg`: icono.
